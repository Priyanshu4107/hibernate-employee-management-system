# Hibernate Employee Management System

A Java-based Employee Management System developed using **Hibernate ORM** and **MySQL**. The project demonstrates how Hibernate can be used to perform database operations without writing traditional JDBC boilerplate code.

## 🚀 Features

* Add new employees
* View employee details
* Update employee information
* Delete employees
* Search employees
* Hibernate ORM-based database operations
* MySQL database integration

## 🛠️ Technologies Used

* Java
* Hibernate ORM
* MySQL
* Maven
* SQL
* IntelliJ IDEA / Eclipse

## 📚 Hibernate Concepts Used

* Hibernate Configuration
* `SessionFactory
* `Session
* HQL
* Entity Mapping
* Hibernate Annotations
* CRUD Operations
* Transaction Management

## ⚙️ How to Run

1. Clone the repository.
2. Create a MySQL database.
3. Configure the database credentials in the Hibernate configuration file.
4. Update the required dependencies in pom.xml.
5. Run the main Java class.
6. Perform employee CRUD operations.

## 🎯 Purpose

This project was created to practice **Hibernate ORM, database connectivity, entity mapping, and CRUD operations** in Java.
